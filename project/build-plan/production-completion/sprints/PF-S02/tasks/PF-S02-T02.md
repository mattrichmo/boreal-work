1. Extract only the store transaction/profile/execution/operation/acceptance seams required by later tasks; preserve public behavior and avoid a framework rewrite.
2. Move shared decoding and transaction ownership helpers to one named location so nested BEGIN calls and duplicated policy are not introduced.
3. Define internal storage request/result interfaces from the frozen contract and expose registration points for later modules.
4. Keep domain evaluation in Rust domain/application; do not translate status authorization into a second SQL predicate.
5. Run baseline and focused tests before and after the extraction and explain any mechanically necessary API adjustments.
6. Publish exact new-file ownership and root-module integration requests so execution and evidence agents can work without editing the monolith concurrently.

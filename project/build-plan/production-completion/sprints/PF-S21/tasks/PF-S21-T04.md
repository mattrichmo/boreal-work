## 5. Ordered implementation / investigation instructions

1. Fetch the release through each approved public distribution path into a clean native machine/prefix.
2. Verify artifact authentication/checksum, absolute installed binary identity and complete TUI/workflow/share assets.
3. Run the required init/two-project isolation/parallel planning/genuine proof/review/finish/memory/TUI smoke using the published install.
4. Run supported upgrade from the prior release and verify active-service/schema compatibility and actual installed readback.
5. Record platform/runtime/download/source identities and distinguish distribution failures from application failures.
6. Acknowledge success only after actual published-path behavior is observed; local candidate tests do not substitute.

## 5. Ordered implementation / investigation instructions

1. Export a single canonical decision/action API and approved fact types through the domain crate root.
2. Audit remaining helper evaluators for semantic duplication; retire them or make them delegate to the canonical functions.
3. Provide typed integration examples to store/application owners without editing their policy locally.
4. Document required snapshot facts, error behavior and absence versus corruption semantics.
5. Run full domain tests and compile adapter consumers on the integrated branch to catch incompatible signatures early.
6. Record source search evidence that no writable display-status mutation API was introduced.

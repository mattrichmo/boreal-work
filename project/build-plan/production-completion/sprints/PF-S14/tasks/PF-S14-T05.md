## 5. Ordered implementation / investigation instructions

1. Guide authorized independent reviewers to exact immutable submissions and all current/failed evidence.
2. Distinguish reject/return/reconcile, expiry recovery, failed execution, pause and hard-hold resolution.
3. Offer typed exception/waiver actions only to authorized operators with required reason/comment/revision/scope context.
4. Route stale fences, restored epochs and unknown operation outcomes to safe readback/recovery rather than retry loops.
5. Explain physical-stop/resource disposition before replacement work.
6. Preserve all failed receipts/reviews/attempts and reference them in remediation guidance.

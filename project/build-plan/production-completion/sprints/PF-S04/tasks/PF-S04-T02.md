## 5. Ordered implementation / investigation instructions

1. Revalidate canonicalized database and workspace paths after lexical normalization; explicitly reject traversal and forbidden symlink targets.
2. Use descriptor-relative or equivalent platform-safe opening where needed to avoid checking one path and opening another after a race.
3. Apply the same selected-project policy to database sidecars, sockets, evidence blobs, gate files, source attachments, memory paths and backup destinations.
4. Define explicit authorized external paths separately from implicit project-local paths; do not silently broaden confinement to make tests pass.
5. Test symlink replacement, nested directories, spaces, non-ASCII names, moved roots and parent traversal on supported filesystems.
6. Document residual local-OS trust assumptions and avoid claiming protection from a process allowed to rewrite the database directly.

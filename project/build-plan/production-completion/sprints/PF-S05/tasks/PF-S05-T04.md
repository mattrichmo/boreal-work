## 5. Ordered implementation / investigation instructions

1. Wire authenticated envelopes to the one application executor and durable operation lifecycle in the production host.
2. Bound queue capacity, request memory, wait time and cancellation handling with typed busy/outcome semantics.
3. Apply approved fairness across heartbeat, operator recovery, planning and ordinary work without allowing starvation.
4. Measure queue wait, transaction hold and external-job time separately; do not label the whole latency as database time.
5. Ensure request cancellation before commit has an explicit outcome and cancellation after commit remains readback-safe.
6. Preserve one elected service writer plus consistent reader connections per project.

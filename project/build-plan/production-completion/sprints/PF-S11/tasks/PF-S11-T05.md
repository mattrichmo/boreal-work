## 5. Ordered implementation / investigation instructions

1. Use a dedicated safe Git workspace and deterministic manifest for the approved publication layout.
2. Persist a publication job/intent before external Git writes and run Git outside the canonical work transaction.
3. Record expected parent/content identity and actual resulting commit; reconcile commit-created-before-database-acknowledged failures by readback.
4. Handle concurrent human edits, merge conflicts and interrupted publication without destructive reset or fabricated success.
5. Make replay idempotent against the original publication identity and preserve failed jobs.
6. Expose published-at-named-revision authority separately from live database drafts.

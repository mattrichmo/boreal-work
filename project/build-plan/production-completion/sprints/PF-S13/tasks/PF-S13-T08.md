## 5. Ordered implementation / investigation instructions

1. Use one machine-envelope serializer and stable exit-code mapping across all commands and aliases.
2. Reserve stdout for machine output when requested and route diagnostics/progress safely to stderr.
3. Include project/database/snapshot/operation identities and typed gaps without serializing secrets or internal backtraces by default.
4. Make help/discovery reflect actual required flags, auth, consequences and compatible versions.
5. Provide operation-show/readback with enough authority and request identity to resolve unknown outcomes safely.
6. Sanitize untrusted terminal control sequences in human-readable output while preserving machine JSON escaping.

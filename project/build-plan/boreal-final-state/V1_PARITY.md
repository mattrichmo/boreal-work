# v1 parity checklist

This checklist is executed in BW-S11-T04. It records useful behavior to preserve, not a mandate to restore v1's central write-through authority.

- [ ] Capture first, classify later.
- [ ] Global management works without a repository.
- [ ] Stable logical project identity survives path moves/unlink.
- [ ] Linked source outage remains stale/unknown, never false zero/complete.
- [ ] Original capture provenance survives promotion/handoff where source is known.
- [ ] Global can show cross-project attention without stealing project execution state.
- [ ] Project next/readiness respects dependency truth.
- [ ] Project attempts/evidence/review/finish retain failure/history and recovery behavior.
- [ ] Backup/update recovery preserves accepted records.
- [ ] Deliberate v2 departure: Global does not silently mutate/complete project execution.

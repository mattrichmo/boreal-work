## Work

1. Add a Global-specific backup package type using SQLite online backup.
2. Manifest source schema ID/version, database ID, revision, byte count/checksum, producer identity and SQLite runtime.
3. Reopen the copied DB without migration and validate Global singleton/state/operation/audit/history invariants.
4. Publish backup package only after DB and manifest validate.

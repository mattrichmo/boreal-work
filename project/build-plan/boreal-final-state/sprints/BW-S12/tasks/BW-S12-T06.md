## Work

1. Use an exact released/candidate compiled binary, pinned fixture and isolated roots. Demonstrate CLI-only use without Node, TTY, Cargo or a writable host home; record required OS/ABI/runtime dependencies rather than claiming a universally static binary.
2. On the supported Linux target, qualify an isolated container or equivalent environment with an explicitly persisted state root and local runtime/socket permissions. Restart the process/environment and read back the same canonical state.
3. Also destroy an ephemeral fixture and prove its data is not silently treated as recovered. Reprovisioning binaries is not state persistence. Missing socket/process/filesystem capabilities return actionable unsupported/environment outcomes, never false passes.
4. Exercise two enrolled worker sessions in separate processes/worktrees against one project authority: race for the same task, continue independent tasks, interrupt one and recover without stealing the other lease or files.
5. Keep separate Global/project roots and explicit workspace binding. A cloned checkout must not fork shared live execution authority accidentally; do not place operational databases, sockets or credentials in Git or shared network SQLite.
6. Record host, target, image/runtime, binary hash, fixture, constraints and checks. A simulated client is a contract test; actual named-harness and native-install acceptance remain S11 release requirements. No claim of access to a user ChatGPT environment from reading its GitHub repo.

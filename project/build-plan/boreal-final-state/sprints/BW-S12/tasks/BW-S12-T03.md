## Work

1. Guide an operator from an empty project through source/config selection, enrolled worker and scoped session setup. Test a genuinely enrolled Agent; using an Operator principal is not proof that automatic worker dispatch works.
2. Preserve actor, session, harness, project, source/config and action descriptor identity through start/resume/checkpoint/heartbeat/renew/release/finish. The harness owns liveness scheduling; heartbeat is not renewal and neither extends the hard deadline.
3. Capture/bind the changed result to the current attempt before verification and submission. Keep the original claim inputs immutable; invalidate stale evidence/review applicability when result or proof identity changes.
4. Expose canonical review decisions and closeout receipts/summary readback after client restart. Keep needs-review, rejected, released, cancelled and accepted distinct. Independent approval stays role- and submission-bound.
5. Qualify lost replies, long tool calls, expired leases, stale fences, service/process restart and handoff. Read back an uncertain operation before retry; preserve abandoned work before reassigning. Use S00-T05 recovery and distinct obligation resolution rather than replacing them.
6. Check authorization again at each mutation boundary. A returned guide, confirmation flag or forged role/session field cannot create grants or permit self-attested trusted evidence.

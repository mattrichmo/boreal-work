## Work

1. Complete source capture/search/show/verify, decisions/supersession, context search/show and cited memory draft/review/publish/retrieve using the current source/memory design, not a new vector store.
2. Return bounded context with source version/digest, citation locators, observation revision and freshness. Archived, superseded, missing and access-denied are explicit; never replace evidence with an uncited chat recollection.
3. Persist final summary/result witness bytes through the existing artifact/source layer. Inspect/readback must survive deletion of the caller temporary file and restart of the original agent session.
4. Keep logical project/artifact identity separate from host absolute paths. Local file operations remain explicit local capabilities; context/results needed by an external adapter have bounded inline or resolvable identity-based reads with size/digest/scope checks.
5. Treat source documents, filenames and task text as untrusted data, not executable guidance. Refuse cross-project traversal and redact credentials from diagnostics.
6. Document the recovery set: project/Global database backups, source/artifact bytes and Git-backed curated memory have distinct coverage. A database-only restore cannot be called a full project recovery when referenced knowledge is absent.

## Required revision 4 general-work delta

1. Reuse the existing source catalog/blob store and immutable source versions for generated artifacts. Do not create a parallel file authority. Add bounded output/input relationships with producing work/attempt, requirement key, role, media type, byte count, digest/version, availability and provenance.
2. Distinguish input source, produced deliverable, validation evidence and accepted submission. Registering a file proves capture, not usefulness, ownership, acceptance or deployment. Preserve original files and revisions on replacement.
3. Resolve accepted input artifacts for downstream work deterministically. If a brief or logo master changes, keep historical outputs and surface affected consumers as requiring revalidation; do not silently retarget links or reopen every descendant automatically.
4. Make binary creative assets usable without forcing text extraction to succeed. Missing/corrupt blobs, access denial, out-of-scope paths, unsafe archives and unsupported media yield explicit bounded errors. Never execute embedded instructions.
5. Materialization/export/backup must preserve identity independently of absolute paths. Verify size and digest on another permitted root after original temporary files disappear. Preserve referenced bytes across restart and document retention; garbage collection cannot remove accepted or in-use artifacts silently.
6. Assemble bounded context packs with requirement, accepted-input and citation versions. Include only authorized project material, redact credentials and preserve reviewable rights/source provenance where relevant. Repair fresh-project empty-memory behavior; source/context reads must work via the supported service instead of requiring unsafe service shutdown.

## Work

1. Complete source capture/search/show/verify, decisions/supersession, context search/show and cited memory draft/review/publish/retrieve using the current source/memory design, not a new vector store.
2. Return bounded context with source version/digest, citation locators, observation revision and freshness. Archived, superseded, missing and access-denied are explicit; never replace evidence with an uncited chat recollection.
3. Persist final summary/result witness bytes through the existing artifact/source layer. Inspect/readback must survive deletion of the caller temporary file and restart of the original agent session.
4. Keep logical project/artifact identity separate from host absolute paths. Local file operations remain explicit local capabilities; context/results needed by an external adapter have bounded inline or resolvable identity-based reads with size/digest/scope checks.
5. Treat source documents, filenames and task text as untrusted data, not executable guidance. Refuse cross-project traversal and redact credentials from diagnostics.
6. Document the recovery set: project/Global database backups, source/artifact bytes and Git-backed curated memory have distinct coverage. A database-only restore cannot be called a full project recovery when referenced knowledge is absent.

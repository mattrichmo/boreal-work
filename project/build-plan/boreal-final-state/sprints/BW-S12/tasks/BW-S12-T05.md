## Work

1. For every required Project workflow and shared capability contract, expose one supported typed application route and its client mapping. Reuse existing protocol DTOs; generate or validate TS/client schemas rather than hand-maintaining conflicting semantics. Global daily/Inbox/Send routes are completed by their S05-S09 owners against this contract, not prerequisites for this task. Mark undelivered capabilities unavailable; do not create a circular wait on S07/S09.
2. Guide/next must return an executable registered action with exact typed required inputs or an actionable idle/blocked/needs_operator/unavailable response. Resolve missing inputs explicitly; do not loop forever on advisory work show.
3. Keep trusted action provenance, shell:false argv safety where local execution is used, and ordinary descriptive data separate. No generic execute-SQL/execute-shell escape hatch.
4. Preserve application rejection/conflict/busy/failed/unchanged versus transport success, request size bounds, cursor/revision/freshness rules and canonical operation readback. Preserve strict per-attempt replay rules instead of treating every retry as interchangeable.
5. Run a minimal non-CLI client over the current local protocol for discover/read/claim/checkpoint/result/proof/finish-or-review/readback and representative wrong-authority cases. Keep semantic decisions in Rust; do not make Unix-socket bytes into a new business API.
6. Align installed Codex/Claude skills, registry/help and TUI calls with the same capability matrix. Full MCP packaging, public HTTP and remotely hosted state remain the separately gated successor in INTERFACE_ROADMAP.md.

# Handoff Summary

## Purpose

Use this template as an output contract for workflows that need a human-readable handoff summary artifact. Templates shape prose and summaries; CLI commands remain the canonical state writers.

## Required Fields

- Scope
- Source or evidence references
- Current state
- Decision or action taken
- Risks and unknowns
- Next action

## Template

### Scope

Describe the bounded project, work item, source, or memory page.

### Summary

Write the smallest truthful summary that preserves uncertainty.

### Details

### Risks And Open Questions

List unresolved conflicts, stale truth, missing evidence, or follow-up checks.

### Next Action

Name the next Boreal workflow or CLI command to run.

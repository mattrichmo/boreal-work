# Project Closeout

## Purpose

Use this template as an output contract for workflows that need a human-readable project closeout artifact. Templates shape prose and summaries; CLI commands remain the canonical state writers.

## Required Fields

- Scope
- Source or evidence references
- Current state
- Decision or action taken
- Sprint and task breakdown
- Git checkpoints or reason codes
- Risks and unknowns
- Next action

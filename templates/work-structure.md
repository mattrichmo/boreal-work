# Work Structure

## Purpose

Use this template as an output contract for workflows that need a human-readable work structure artifact. Templates shape prose and summaries; CLI commands remain the canonical state writers.

## Required Fields

- Scope
- Source or evidence references
- Current state
- Decision or action taken
- Git checkpoint boundaries
- Risks and unknowns
- Next action

# Prior Art And Originality Note

Boreal is informed by local-first issue trackers, Git-native task systems, and agent workflow tools, including Beans/Beads-style workflows. Its implementation is independent and TypeScript-native, and this repo should not copy source code or implementation-specific prose from those projects.

The product category includes repo-local work tracking, agent-friendly CLI flows, local search, and project memory. Those category-level ideas do not determine implementation ownership or attribution.

Boreal's distinct surface is evidence-backed closure, verification records, knowledge sources, claims, decisions, reservation leases for agents, runtime operation logs, context packs, vault workflows, repairable generated artifacts, and JSON-first contracts across CLI, MCP, daemon, and console surfaces.

Public wording should describe Boreal as an independently implemented local runtime for evidence-backed work, project memory, and agent handoff. Avoid "derived" language unless a section is explicitly documenting prior art, and prefer `bwrk agent guide` or `bwrk agent status` in new agent-facing examples when a compatibility shortcut is not required.
